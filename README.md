# QD 观察台

基于参考页面重新设计的本地网页。保留基金搜索、自选、申购限额、估值、历史表现、跨境 ETF 与全球行情功能，采用极简数据画布界面，适合桌面和手机使用。

## 运行

在此目录运行：

```powershell
python -m http.server 8877 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8877/`。页面无需安装前端依赖。如果该端口已被占用，可以换用其他空闲端口。

## 数据说明

基金与市场数据由浏览器直接读取天天基金、腾讯行情和 CNBC 的公开接口。今年涨幅与历史净值使用天天基金公开净值序列计算，基准为上一年最后一个净值日的累计净值；基金未成立或缺少基准净值时显示缺失，不补零。预置持仓与部分申购额度继承自参考页面；第三方接口或披露内容变化时，页面数据可能延迟或失效。自选、排序、基金列表和估值快照仅保存在当前浏览器。估值仅供参考，申购前请核对基金公司公告。

基金搜索框会即时筛选当前列表，同时查询可添加的基金。添加或查看已有基金后会收起搜索结果并定位到对应基金；按 Esc 可清空搜索。

重点基金图和每只基金详情图增加同期沪深 300 对比。指数日线取自腾讯公开接口；两条线使用同一组基金净值日期，以最近一个不晚于该日期的指数收盘价对齐，并分别从共同起点归一为 0%。图中的百分比是所选区间收益率，基金原始累计净值仍单独显示。指数历史行情不可用时明确显示缺失，不生成示意曲线。

电脑端展开基金后，左侧展示净值走势与历史表现，右侧直接展示持仓；较窄屏幕恢复纵向排列。

手机端展开基金时，先显示走势和前五项持仓，其余已展示持仓可按需展开（最多前二十项）；阶段表现压缩为两行，时间区间可横向滑动。没有估值快照时不显示空的历史估值模块。

`app.js` 保留参考页面的数据与计算逻辑，`ui.js` 调整筛选和页面交互，`styles.css` 与 `index.html` 为重新设计的界面。该项目与旁边的财务台账相互独立。
